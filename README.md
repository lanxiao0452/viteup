## Usage

> [!NOTE]
> You can safely delete the `.github` folder. It is only used to keep Viteup’s dependency versions up to date in the GitHub repository and isn’t needed for development.

```bash
npx degit lanxiao0452/viteup my-viteup-app
cd my-viteup-app
pnpm install
```
